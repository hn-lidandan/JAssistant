# 数据库规范

本规范基于阿里巴巴Java开发手册。

### 1. 表设计

*   **【强制】** 表名、字段名必须使用小写字母或数字，禁止出现数字开头，禁止两个下划线中间只出现数字。
*   **【强制】** 主键索引名为 `pk_`字段名；唯一索引名为 `uk_`字段名；普通索引名则为 `idx_`字段名。
*   **【强制】** 小数类型为 `decimal`，禁止使用 `float` 和 `double`。
*   **【强制】** 如果存储的字符串长度几乎相等，使用 `char` 定长字符串类型。
*   **【强制】** `varchar` 是可变长字符串，不预先分配存储空间，长度不要超过 5000。
*   **【强制】** 表必备三字段：`id`, `gmt_create`, `gmt_modified`。

### 2. 索引

*   **【强制】** 业务上具有唯一特性的字段，即使是多个字段的组合，也必须建成唯一索引。
*   **【推荐】** 在 `varchar` 字段上建立索引时，必须指定索引长度，没必要对全字段建立索引。
*   **【推荐】** 利用覆盖索引来进行查询操作，避免回表。

### 3. SQL 语句

*   **【强制】** 不要使用 `count(列名)` 或 `count(常量)` 来替代 `count(*)`，`count(*)` 是 SQL92 定义的标准统计行数的语法，跟数据库无关，跟 NULL 和非 NULL 无关。
*   **【强制】** `count(distinct col)` 计算该列除 NULL 之外的不重复行数，注意 `count(distinct col1, col2)` 如果其中一列全为 NULL，那么即使另一列有不同的值，也返回为 0。
*   **【强制】** 当某一列的值全是 NULL 时，`count(col)` 的返回结果为 0，但 `sum(col)` 的返回结果为 NULL，因此使用 `sum()` 时需注意 NPE 问题。
*   **【强制】** 使用 `ISNULL()` 来判断是否为 NULL 值。
*   **【强制】** 不得使用 `*` 作为查询的字段列表，需要哪些字段必须明确写明。
*   **【推荐】** `in` 操作能避免则避免，若实在避免不了，需要仔细评估 `in` 后边的集合元素数量，控制在 1000 个之内。

### 4. ORM

*   **【推荐】** `resultMap` 中 `association` 和 `collection` 的 `fetchType` 默认是 `lazy`，不要改成 `eager`。
